# 네이버 예약 자동 수집 (아스타나키즈 · 30분마다 판매입장권 · 신규방문자)

매일 아침 **09:40** POS 메인 PC(실행기 `nice-pos`)가 네이버 스마트플레이스 **예약 → 예약현황 → 일간 · 전체**에서
**어제**를 읽어 A 의 네이버 칸을 채웁니다. (`.github/workflows/naver-collect.yml`, `apps/collector/src/naver.ts`)

- 판매입장권 = 회차 칸의 **이용완료** 수 (1건 = 1장). 상품은 **평일 무제한 · 야간자유 입장** 두 가지만
- 신규방문자 = 그 칸을 누르면 나오는 완료자 목록에서 이름 밑이 **완료 1** 인 사람 수
- 10:00 ~ 19:30 칸만. 어제 + 지난 7일 중 비어 있는 날 (PC가 꺼졌던 날)
- 사람이 A 에서 직접 넣은 날은 덮지 않음
- 이름 · 전화번호는 읽지도 저장하지도 않음 (숫자만 셈). 공개 기록에는 칸 수 · 같음/다름만

## 처음 한 번 — 네이버 로그인 (POS 메인 PC)

1. 첫 자동 실행이 끝나면 `C:\actions-runner\naver-login.cmd` 가 생깁니다. **더블클릭**
2. 뜨는 브라우저 창(크롬과 별개)에서 법인 네이버 아이디로 로그인, **로그인 상태 유지** 체크
3. 예약 관리 화면이 보이면 자동으로 저장하고 끝 — 창을 닫으면 됩니다
4. 그다음부터는 매일 아침 이 로그인으로 읽습니다. **로그인이 풀린 날만** 다시 1~3

- 저장되는 것은 비밀번호가 아니라 로그인 상태(`C:\actions-runner\_work\_tool\naver-login\state.json`)이고, 이 PC에만 있습니다.
- 직원들이 쓰는 크롬과는 별개라 서로 부딪히지 않습니다.
