# 키즈대관 — 통합데스크 [대관] → 보고 앱 (2026-11-10)

어린이집 · 유치원 같은 단체가 키즈존을 빌려 쓰는 날의 기록.

## 사장님 결정 (2026-11-10)
- **대관료 매출은 돈이 들어온 날 그대로** — 자금 기록(현금 입출금 기록)과 맞추려고. 자금 기록 원화 계좌 입금 중 보낸 사람 · 적요에 '어린이집' · '유치원'이 있거나 '키즈'와 '대관'이 함께 있으면 그날 키즈입장 매출에 더함 (`packages/core/src/cash.ts isRentalRow` · `metrics.ts`). 보고 앱 키즈 계산식 줄에 "+ 대관 ○원"으로 보임
  - 예: 10-16 에 입금하고 11-10 에 이용 → 대관료는 10-16 키즈입장 매출
- 하지만 **단체가 실제로 와서 쓴 날**도 보고 앱에 남아야 함 → 대관이 있는 날 키즈 통합데스크에서 **[대관]** 을 눌러 단체 이름 · 입금일을 적고 저장 (통합데스크 쪽은 사장님이 키즈 통합데스크 작업에서 만듦)
- 키즈 실시간 '오늘 입장' 넷째 칸은 **키즈대관**(그날 건수) — 예전 '이벤트' 입장 수 칸을 바꿈(이벤트는 11월 말에 끝나고 매출과 이어지지 않음). 누르면 "단체 이름 (입금 10/16)" 한 줄씩 · 적혀 있으면 시각 · 인원 · 대관료 · 메모. **매출에는 더하지 않음** (입금한 날 이미 들어감)

## 통합데스크가 보내는 것
- 저장할 때마다(고치거나 취소해도) 클라우드 `boards/{보고 열쇠}/deskStats/rental-{이용일}` 에 덮어씀 — 설문 보고함 · 키즈 실시간 · 이벤트 입장 수와 같은 보고 열쇠, 문서 칸은 `json` · `at` 둘
- 그날 대관을 모두 취소하면 빈 목록(`"list": []`)으로 덮어씀 → 0건
  ```json
  {
    "type": "astanakiz-rental", "v": 1,
    "day": "2026-11-10", "sentAt": "2026-11-10 09:40",
    "list": [
      { "name": "○○어린이집", "paidOn": "2026-10-16", "amount": 200000, "people": 18, "time": "10:00", "memo": "오전 단체" }
    ]
  }
  ```
  | 칸 | 뜻 | 꼭 |
  |---|---|---|
  | `day` | 이용일 (문서 이름의 날짜와 같아야 함) | 꼭 |
  | `list[].name` | 단체 이름 (30자까지) | 꼭 |
  | `list[].paidOn` | 입금일 `YYYY-MM-DD` (모르면 `null` → "입금일 안 적음") | |
  | `list[].amount` | 대관료 (참고만 — 매출에는 입금한 날 들어감) | |
  | `list[].people` | 인원 | |
  | `list[].time` | 시작 시각 `HH:MM` | |
  | `list[].memo` | 메모 (40자까지) | |
- **손님 연락처는 보내지 않음** — 이름 · 메모가 전화번호처럼 보이면 보고 앱이 그 줄 · 그 칸을 버림. 하루 20건까지
- 검사 `packages/core/src/deskRental.ts parseDeskRental` · 보여 줄 글 `rentalLabel` · 시험 `packages/core/test/deskRental.test.ts`
- 보고 앱은 키즈 실시간을 열 때 · 새로고침 때 그날 문서를 읽음 (`apps/view/src/data/firebase.ts deskRentalDay`)
