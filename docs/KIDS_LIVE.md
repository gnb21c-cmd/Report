# 키즈 실시간 — 통합데스크 → 보고 앱 (2026-10-16)

총괄 관리자가 출근하지 않았어도 **폰 한 화면**에서 지금 키즈를 본다 (사장님 2026-10-16).
보고 앱(B) 첫 화면 **'입장권 판매 총 수량' 칸을 누르면 '키즈 실시간'** 으로 넘어간다 (`apps/view/src/screens/KidsLive.tsx`). 위에서 아래로 오늘 입장 → 열쇠 운용 → 입장료 매출 → 네이버 예약 (열쇠를 오늘 입장 바로 밑으로 — 사장님 10/16)

- **오늘 입장**: 총 판매수 = 네이버 이용완료 + 현장(+1타임) · 서비스 키(판매 아님)는 따로
- **입장료 매출**: 받은 때 기준 — 입장권 장수 × 그날 단가(`kidsPrice`, 평일 12,000 · 휴일 14,000) + 결제한 초과요금 = 합계 · 아직 받지 않은 초과요금은 따로 한 줄
- **네이버 예약**: 오늘 합 완료 · 미입장 · 잔여 + 시간 칸(예약 있는 칸만, [모든 시간 보기]) · 지금 칸 칠함
- **열쇠 운용**: 사용 n/45 · 빈 열쇠 · 현장 판매 가능 · 45칸 번호(색 = 반납 조건: 이용 중 · 반납 시간 10분 안 분홍 · 넘으면 빨강 · 서비스 키 점선)
  → 번호를 누르면 아래에서 올라오는 창: **손님 이름 · 전화번호 그대로**(전화 걸기 · 번호 복사) · 열쇠 · 상태(초과요금) · 입장 · 반납 · 수량 · 예약번호/POS 번호 · 대리예약 방문자 · 서비스 키 수령인

**열 때 · 아래로 당겼다 놓을 때 · [새로고침] · 앱으로 돌아올 때** 다시 읽음. 맨 위 "통합데스크 14:05:12 기준 · 방금/n분 전".
3분 넘게 새 현황이 없으면 "통합데스크 소식이 n분째 없어요", 오늘 현황이 없으면 "오늘 현황이 아직 없어요 — 마지막 현황 …".

## 흐름
1. 키즈 POS 통합데스크(gnb21c-cmd/astanakiz, 다음 판 ~)가 **1분마다 · 바뀌면 5초 안에** 지금 현황 글(`astanakiz-live`)을
   클라우드 `boards/{열쇠}/deskLive/now` 에 **덮어씀** (설문 보고함과 같은 보고 열쇠 · 로그인 없이). 통합데스크 쪽 설명 · 글 모양은 astanakiz `docs/LIVE.md`
2. B 가 그 한 문서를 읽어(`apps/view/src/data/firebase.ts deskLiveNow`) 검사(`packages/core/src/deskLive.ts parseDeskLive` — 모양이 틀리면 안 보임)한 뒤 그림

## 처음 한 번 (사장님)
1. **Firebase 콘솔 → Firestore Database → 규칙** 에 이 저장소 `firebase/firestore.rules` 전체를 붙여 넣고 [게시] (`deskLive` 규칙이 새로 들어감 — Deploy 는 화면만 올림)
2. 키즈 POS 통합데스크를 '폰 실시간 현황'이 들어간 판으로 → 운영 설정 → 설문조사: 보고 열쇠(설문 보고함과 같은 것) · **폰 실시간 현황 켜짐**
3. 1분 안에 통합데스크 설정에 '마지막: … 보냄' → 보고 앱 '입장권 판매 총 수량' → 키즈 실시간에 보이면 끝
- 규칙을 넣기 전에는 B 에 "키즈 실시간을 읽을 수 없습니다 — 클라우드 보안 규칙에 deskLive …", 통합데스크에는 '실패 … (403)'

## 규칙 (`firebase/firestore.rules` → `deskLive`)
- 읽기: 열쇠를 아는 폰(B) · 쓰기(만들기 · 고치기): 로그인 없이 — 문서 이름 `now` 만 · 칸은 `json` · `at` 만 · `json` 은 100,000자 미만 글 · `astanakiz-live` 가 들어간 `{…}` · 그 매장 보고 설정(`settings/main`)이 있는 열쇠만
- 지우기는 입력 계정만 · 매출 · 설정 등 다른 칸은 전처럼 입력 계정만

## 개인정보
- 저장소 원칙은 개인정보를 다루지 않는 것이지만, **키즈 실시간만은 사장님 지시(2026-10-16)로 열쇠를 가진 손님의 이름 · 전화번호를 보여 줌** (열쇠 미반납 때 관리자가 전화)
- **문서 하나(`now`)만 덮어씀** → 반납 · 퇴장한 손님은 다음 현황에서 빠지고 클라우드에 지난 기록이 쌓이지 않음 · B 는 폰 저장소에도 남기지 않음(화면을 열 때마다 새로 받음)
- 체험판 자료(`apps/view/src/data/demoDeskLive.json`)는 통합데스크 체험판의 가짜 손님 · 전화번호는 누가 봐도 가짜(010-0000-00NN)
- 열쇠가 새면 열쇠를 바꾸고(docs/SETUP.md) 통합데스크 보고 열쇠도 새것으로
