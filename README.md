# report — 매장 POS 일일 보고 시스템

카페 메인 POS · 키즈 POS(OK포스)의 매출을 꺼내, 회사 안 몇 사람이 폰에서 **전날까지의 보고**를 언제든 보도록 하는 내부용 시스템입니다.
아스타나 앱(`gnb21c-cmd/astana`)과는 별도로 운용하며, 그쪽에서 만든 POS 읽기 코드·점검 결과·보고 계산 방식을 가져다 씁니다.

| 번호 | 프로그램           | 설치 위치                |
| ---- | ------------------ | ------------------------ |
| ①    | POS 자료 추출      | 카페 메인 POS · 키즈 POS |
| ②    | 집계 · 분석 · 보고 | 폰 앱 안 (서버 없음)     |
| ③    | 폰 보기            | 보는 사람 폰             |

- 검토 · 가능성 · 실행 계획: [docs/PLAN.md](docs/PLAN.md)
