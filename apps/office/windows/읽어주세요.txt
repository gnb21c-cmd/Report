매출 보고 — 사무실 PC (C) · 직원 PC (A)

구성
  C (사무실 PC 한 대, 24시간 켜 둠): 직원들이 넣은 자료를 받아 날짜별로 합치고, 폰 보고 앱(B)에 올림
  A (직원 PC 최대 5대 정도): 바탕화면 '매출 보고 입력' 아이콘 → C 의 입력 화면이 전체 화면으로 열림
  B (대표 · 관리자 폰): 보고 앱 (설치 주소로)

C 설치 (처음 한 번, 사무실에 켜 둘 PC 에서)
  1. 압축을 모두 풉니다.
  2. install-c.bat 더블클릭 → "이 앱이 PC를 변경하도록 허용" 창에서 [예]
  3. 클라우드 올리기 계정 이메일 · 비밀번호를 넣습니다. 아직 없으면 Enter (= 시험 모드: C 에만 쌓임)
  4. 사무실 비밀번호를 정합니다 (없으면 Enter). 손님 와이파이가 사무실 공유기와 같으면 꼭 정하세요.
  5. 끝에 나오는 "이 PC 이름 · 주소" 를 적어 둡니다. 이 PC 는 끄지 말고 켜 두세요 (재부팅해도 저절로 시작).

A 설치 (직원 PC 마다 한 번)
  1. 이 폴더(또는 install-a.bat · install-a.ps1 두 파일)를 직원 PC 에 복사
  2. install-a.bat 더블클릭 → C 를 저절로 찾아 바탕화면에 "매출 보고 입력" 아이콘을 만듦
     (못 찾으면 C 설치 때 적어 둔 주소를 넣음)

매일 (전날 영업 마감 자료 — 각자 맡은 칸만 넣어도 됨)
  1. 바탕화면 "매출 보고 입력" → 날짜가 어제로 열림
  2. ① 네이버 예약 표: 30분마다 판매입장권 수 · 신규방문자 수
  3. ② 백오피스 https://nice.okpos.co.kr (총괄 아이디) → "영수증별 매출 상세현황"
       매장 [카페아스타나] 하루 조회 → 엑셀 받기 → 왼쪽 칸에 올림
       매장 [아스타나키즈] 하루 조회 → 엑셀 받기 → 오른쪽 칸에 올림
       ※ 매장 [전체]로 받으면 섞여서 안 됩니다.
  4. ③ 처음 보는 상품은 분류(바리스타 · 베이커리 · 키친 · 기타)를 한 번 확인
  5. [입력완료 · 보고자료 업로드] → 끝.  중간에 멈출 때는 [임시저장] (이 PC 에만 보관)

작년 비교선: 입력 화면 아래 "지난 자료 한꺼번에 넣기" — 상품별(일자별) 엑셀을 기간 길게 받아 매장별로 한 번씩

지우기: C 는 uninstall-c.bat, A 는 바탕화면 아이콘만 지우면 됨
문의: C 의 C:\ProgramData\PosReport\logs\office.log 파일을 보내 주세요.
