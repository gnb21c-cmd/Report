매출 보내기 (사무실 PC 한 대 — 카페 · 키즈 함께)

설치 (처음 한 번)
  1. 압축을 모두 풉니다.
  2. install.bat 더블클릭 → "이 앱이 PC를 변경하도록 허용" 창에서 [예]
  3. 보내기 계정 이메일·비밀번호를 넣습니다. 아직 없으면 Enter (= 시험 모드: 보내지 않고 읽기만)
  4. 바탕화면에 "매출 보내기", "매출 엑셀 폴더" 두 아이콘이 생깁니다.

매일 (아침에 어제 자료, 또는 저녁 마감 뒤 오늘 자료)
  1. 백오피스 https://nice.okpos.co.kr 총괄 아이디로 로그인
  2. 매출 → "상품별 (일자별)" → 매장을 [카페]로 고르고 날짜 조회 → 엑셀 저장
       저장 위치: 바탕화면 "매출 엑셀 폴더" → 카페
  3. 같은 화면에서 매장을 [키즈]로 바꿔 조회 → 엑셀 저장 → "매출 엑셀 폴더" → 키즈
     ※ 매장 [전체]로 받으면 카페·키즈가 섞여 나눌 수 없습니다. 꼭 매장별로 받아 주세요.
     ※ 조회줄수는 5000 으로 (적으면 잘린 파일이라 보내지 않습니다)
  4. 바탕화면 "매출 보내기" → [보내기] → [카페] ✔ … [키즈] ✔ … 가 보이면 끝

인터넷이 끊겨 있으면 보관했다가, 다음에 보내기를 누르거나 PC 를 켤 때 저절로 보냅니다.
같은 날을 다시 받아 넣으면 그날 자료가 통째로 바뀝니다 (두 번 더해지지 않음).

지우기: uninstall.bat
문의: C:\ProgramData\PosReport\logs\send.log 파일을 보내 주세요.
